# Experimental Benchmark Results & Telemetry

This directory houses all empirical benchmark datasets generated by physical simulation runs in MATLAB R2026a and comparative baselines.

## Dataset Index (`results/raw/`)

| File | Requirement(s) | Seeds | Description |
| :--- | :--- | :--- | :--- |
| **`factorial_30seeds_results.json`** | AT1, AT2 | 42–71 ($N=30$) | Complete 7-arm 2x2 factorial evaluation on unconditional safety invariants. Demonstrates the impact of Warm initialization vs. Cold random initialization and lexicographic curriculum ranking. |
| **`factorial_at51_extended.json`** | AT51 | 46–71 ($N=26$) | High-power evaluation on the conditional bounded-response property, recording simulation budgets to first trigger ($E_{\text{trigger}}$) and post-trigger falsification ($E_{\text{falsify}}$), with Gate 2 stiff solver telemetry. |
| **`factorial_enhanced_3seeds_results.json`** | AT51 | 42–44 ($N=3$) | Initial 3-seed pilot on AT51 capturing early convergence behavior across all 7 evaluation arms. |
| **`baseline_comparison_results.json`** | AT1, AT2, AT51 | Multiple | Comparative evaluation telemetry against traditional falsification frameworks (Breach, S-TaLiRo) and static model checkers (Simulink Design Verifier). |
| **`pilot_synthesis_results.json`** | AT1, AT2, AT51 | N/A | Upfront prompt execution traces from `gpt-4o-2024-08-06` showing Track A STL formalization and Track B scenario parameterization, token counts, and RTAMT dual-witness verification latency. |
| **`tier1_preflight_results.json`** | AT1, AT2 | 42–44 | Pre-flight validation verifying solver stability, signal bounding, and gradient tractability. |

## Data Schema
Each JSON record in the factorial evaluation suites contains:
```json
{
  "requirement": "AT1",
  "seed": 42,
  "arm": "SGX_Warm",
  "falsified": true,
  "simulations_count": 35,
  "sims_to_first_trigger": 1,
  "sims_post_trigger": 34,
  "best_robustness": -0.0521,
  "wall_clock_time_sec": 42.18,
  "gate2_verification": {
    "scr": 1.0,
    "ode15s_rho": -0.0521,
    "rho_diff": 0.0,
    "status": "CERTIFIED_DEFECT"
  }
}
```

## Statistical Reproduction
To compute non-parametric statistical metrics (Medians, IQRs, Mann-Whitney $U$ test, Vargha-Delaney $\hat{A}_{12}$ effect sizes) across these raw datasets, execute:
```bash
python3 scripts/06_compute_rigorous_statistics.py
```
